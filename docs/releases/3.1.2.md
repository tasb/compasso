# Compasso 3.1.2: upgrade notes

Read this whole file before changing anything.

## What changed

- **The presentation's menu no longer scrolls sideways on a wide screen.** `/compasso:present` builds a page whose top menu needed slightly more than its 1100px, so it scrolled even on a large monitor, and more with longer labels (Portuguese). The links now wrap onto a second row when they do not fit, and the light/dark button stays at the right of the first row. On a phone (under 700px) the menu is still one row you swipe.
- Sections leave room for a two-row menu, so a link never hides the section's heading.
- Only `templates/presentation.html` changed. No script, skill, role or configuration changed.

## What is new

Nothing.

## What to do in each project

1. **Update the plugin and restart.** Run `claude plugin marketplace update compasso` and `claude plugin update compasso@compasso`, then restart the session.
2. **Regenerate the presentation (optional).** A presentation built before 3.1.2 keeps the old menu. Run `/compasso:present` to rebuild it.
3. **Coming from 3.1.0 or 3.1.1:** nothing else.
4. **Coming from an earlier version:** read [3.1.0.md](3.1.0.md) and follow its "What to do in each project" section. Its step 2 (configuration) is optional.
