# Compasso 3.1.1: upgrade notes

Read this whole file before changing anything.

## What changed

- The 3.1.0 upgrade notes ([3.1.0.md](3.1.0.md)), step 2, said to run `/compasso:setup`. It is optional: a project without `team.lead_merge_minutes` uses 15 and still validates. Setup only writes the key into `.compasso/project.yaml` so it can be changed later.
- No script, skill or role changed.

## What is new

Nothing.

## What to do in each project

1. **Update the plugin and restart.** Run `claude plugin marketplace update compasso` and `claude plugin update compasso@compasso`, then restart the session.
2. **Coming from 3.1.0:** nothing else.
3. **Coming from an earlier version:** read [3.1.0.md](3.1.0.md) and follow its "What to do in each project" section. Its step 2 (configuration) is optional.
